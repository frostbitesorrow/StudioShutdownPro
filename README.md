# Studio Shutdown Protocol

Studio Shutdown Protocol is an interactive security script developed to prevent high amplitude transient sounds such as pop noises in the audio interface and reference monitors during computer shutdown

## Features

* Hardware Protection: Ensures the user checks physical potentiometers and monitor power switches before system shutdown.
* Controlled Workflow: System shutdown proceeds after confirmation or can be cancelled.
* Graphical User Interface: A clear and readable warning screen designed for studio environments.
